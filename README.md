## これは何？

ブラウザで開くと、ピンク色の携帯ゲーム機「PICOT」が現れます。
液晶のなかには、ドット絵の相棒が 1匹。なでたり、つついたり、ハートを送ったり、ごはんをあげたりして遊びます。

いちばんの特徴は **おえかきパレット**。50 × 50 ドットのキャンバスに自分で描いた絵（または手持ちの画像）が、そのまま液晶のなかの なかまになります。位置も大きさもドットの粗さも、液晶を見ながら調整できます。

- 単一 HTML（`index.html`）／ビルド不要／**外部通信ゼロ**
- 画像はすべて端末内で処理・保存（どこにも送信しません）
- BGM・効果音は Web Audio でその場で合成
- iPad / iPhone / PC のブラウザで動作

## おえかきパレット

- 50 × 50 ドット、**40色**（色相順に 白黒 → 赤 → 肌・オレンジ → 黄 → 緑 → 水色 → 青 → 紫 → ピンク）
- ペン／けす／🪣 ぬりつぶし、ふとさ 1〜3 ドット
- **← もどす / → やりなおす**（30手まで）
- 背景 8種類＋自由な色、PNG 保存、この端末に保存、そのまま「この絵で遊ぶ」

## おと

BGM 3曲（ポップ／おひるね／こもりうた）を、Web Audio の音色ちがいで合成しています。

音だけ聞きたいときは `bgm_preview/` へ（`0_all3.mp3` が3曲つなげたもの）。

## データのあつかい

- 画像・おえかき・にっきは `localStorage` と端末内メモリだけ。**サーバーへは何も送りません**。
- CDN もフォント取得もなし。`index.html` 1枚で完結します。

## ローカルで開く

```bash
git clone https://github.com/<your-name>/picot.git
cd picot
open index.html        # macOS
# または start index.html (Windows) / xdg-open index.html (Linux)
```

`file://` のままで動きます（サーバー不要）。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages**
2. Source: **Deploy from a branch** / Branch: **main** / Folder: **/ (root)**
3. 数十秒で `https://<your-name>.github.io/picot/` が公開されます（`index.html` が自動で開きます）
